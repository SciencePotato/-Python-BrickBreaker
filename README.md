# -Python-BrickBreaker

Side and top wall contacts clamp the ball inside the playfield and reflect
only outward velocity. An inward-moving ball at a wall is not flipped back
outside. Offline regression (no Pygame devices):
`python3 -m unittest test_wall_response`.
